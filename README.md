## About

**MineTune** is a Minecraft mod project for enjoying music while playing. This repository is the public project page and distribution hub for verified releases.

The exact Minecraft versions and loader requirements are listed with each release. Please check the release notes before installing a file.

## Features

- Personal playlist concept for listening to music in-game.
- Music interface and playback-related UI.
- A compact “currently playing” notification concept that can be enabled or disabled.

> Feature availability may differ by build. Only features confirmed in a published release should be treated as available.

## Download

**[Open MineTune Releases](https://github.com/pocn98/MineTune/releases)**

1. Open the release matching your Minecraft version.
2. Read the version and loader requirements in that release.
3. Download the attached `.jar` file.
4. Install the required mod loader, if specified, and place the file in your Minecraft `mods` folder.
5. Launch the matching Minecraft profile.

Do not use a file if its supported Minecraft version or loader is unclear.

## Compatibility

Compatibility is tracked per release rather than assumed across every Minecraft version. Check the release title and notes for the exact supported game version, mod loader, and any known limitations.

## Bug reports and suggestions

If you run into a problem, [open an issue](https://github.com/pocn98/MineTune/issues) and include:

- Minecraft version
- Mod loader and its version
- MineTune file/release name
- The steps that reproduce the problem
- A crash report or relevant log excerpt, if available

Never post account passwords, access tokens, or other private information.
