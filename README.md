## About

**MineTune** is a client-side Minecraft music mod. The included mod metadata describes it as an in-game music player that lets you add local MP3, OGG, or WAV tracks.

This public repository provides compiled `.jar` downloads and user documentation. The source code is not published here.

## Features

- In-game music player interface
- Local music-file library
- Playlist and playback controls

The precise feature set can vary by build. If a feature is unavailable in your version, please report the build name and Minecraft version in an issue.

## Installation

1. Download the `.jar` for your Minecraft version and loader from the table above.
2. Install the matching mod loader and any required dependencies.
3. Place the downloaded file in your Minecraft `mods` folder.
4. Launch the matching Minecraft profile.

For additional troubleshooting, see the [installation guide](docs/INSTALLATION.md).

## Troubleshooting and feedback

[Open an issue](https://github.com/pocn98/MineTune/issues) and include:

- Minecraft version
- Mod loader and version
- The MineTune file you downloaded
- What you were doing when the problem occurred
- Relevant error text or crash-log excerpt

Do not include passwords, session tokens, or other private account information.
