## About

**MineTune** is a Minecraft music mod for playing your own music in-game. The uploaded build metadata describes local audio-file support for formats such as MP3, OGG, and WAV.

This repository distributes compiled `.jar` files and user documentation. Source code is not included in the public repository.

## Features

- In-game music player interface
- Local music-file library
- Playlist and playback controls

Feature availability may vary by build. Report any missing or malfunctioning feature through [GitHub Issues](https://github.com/pocn98/MineTune/issues).

## Installation

1. Download the direct JAR link for your Minecraft version and mod loader above.
2. Install the matching mod loader and any required dependencies.
3. Place the chosen JAR in that Minecraft instance's `mods` folder.
4. Launch the matching Minecraft profile.

See the [installation guide](docs/INSTALLATION.md) for troubleshooting.
